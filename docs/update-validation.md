# PKG 업데이트 검증용 빌드

`0.6.1-rc.1`(빌드 8)은 설치된 `0.6.0`(빌드 7)에서 Sparkle 업데이트를
검증하기 위한 후보 버전이다. 입력기 기능 변경은 없으며 정식 최신 릴리스로
게시하지 않는다. 서명·공증된 PKG를 GitHub prerelease의 고정 버전 주소에
게시한 뒤, 다운로드 바이트를 확인하고 appcast를 게시한다.

검증 순서:

1. 기존 글가드에서 업데이트 확인을 선택해 후보 버전 안내를 확인한다.
2. 안내를 취소하고 다시 확인해 재시도가 가능한지 확인한다.
3. 다운로드 후 입력 중인 글자를 확정하고 ABC로 전환한다.
4. 설치를 진행하고 필요한 관리자 인증은 macOS 창에서 직접 처리한다.
5. 설치된 버전과 실제 실행 중인 입력기 경로·버전을 각각 확인한다.
6. 필요 시 로그아웃·로그인한 뒤 한글 입력과 설정 보존을 확인한다.

공개 피드에 후보 항목을 게시하면 해당 피드를 사용하는 다른 업데이터 포함
빌드에도 노출된다. 게시 전에 이를 확인받는다. 검증 완료 또는 중단 시에는
피드를 검증 전 내용으로 복원하며, 이미 게시한 PKG 바이트는 변경하지 않는다.
PKG 설치와 Sparkle를 통한 다운로드·설치 검증은 구분하여 기록한다.
