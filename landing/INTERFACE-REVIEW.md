## 별도 비교 화면

제품 원본에 비교용 라우트를 추가하지 않고 격리 사본에만 보관한다.
기존 토큰·문구·서체를 유지하고 입력창의 **밀도**만 비교한다. 실제 시각 검증을
통과한 최종 후보로 승인한 것은 아니다.

- 미리보기: http://127.0.0.1:53794/
- `break`: http://127.0.0.1:53794/interface-break
- `variant`: http://127.0.0.1:53794/interface-variants?variant=standard#try-title

`break`는 실제 TypingPad의 320px·본문·넓은 컨테이너와 옆 콘텐츠에 눌린 너비를
한 페이지에 둔다. 입력값·loading·error를 받는 props가 없는 컴포넌트이므로
가짜 상태를 주입하지 않았다. 각 입력창에 직접 입력하고 포커스·초기화를 확인한다.

| 비교안 | 밀도 | 적합한 사용 | 비용 |
| --- | --- | --- | --- |
| 간결하게 (`compact`) | 입력 영역 120px | 짧은 문장 확인 | 장문에서 빨리 스크롤됨 |
| 기본 간격 (`standard`) | 기존 입력 영역 | 현재 페이지의 균형 유지 | 긴 문장 여러 줄에는 공간 제한 |
| 넉넉하게 (`spacious`) | 입력 영역 288px | 여러 줄·문단 확인 | 다음 섹션까지 거리가 늘어남 |

피커에 포커스를 둔 상태에서 좌우 방향키 또는 숫자 1–3으로 전환한다. URL의
variant 값으로 비교안을 공유할 수 있다. 어떤 안도 제품 원본에 승격하지 않았다.

## 남은 검증

CUA에서 브라우저 탭 API는 사용할 수 없었다. Aside 앱 경로에서는 반복해서
“The user changed '/Applications/Aside.app'” 보호 응답을 받아 조작을 중단했다.
다른 도구로 우회하지 않았으며 스크린샷·시각 승인·실제 IME 검증을 주장하지 않는다.
이전 QA.md의 기록도 이번 변경의 화면 검증 증거로 재사용하지 않았다.

코드와 자동 검증은 위 범위에서 반영했다. `break` 관찰, `variant` 시각 비교,
visual-qa의 독립 화면 승인, Lighthouse는 미완료다.
